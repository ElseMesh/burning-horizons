# Burning Horizons world content

This repository contains the authored UNDERNEATH cave package and its source
assets. It is content data, not a standalone application or buildable game.
It is maintained independently from the ElseMesh engine and the Tidewater
example world.

## Repository map

- `world-source.json` is the canonical unsigned world layout: identity, spawn,
  rules, objects, portals, versioned components, and runtime asset references.
  Field definitions live in the [ElseMesh world-source schema](https://github.com/ElseMesh/elsemesh.github.io/blob/main/docs/schemas/world-source.schema.json).
- `presentation.json` supplies loading-page copy and stages that the exporter
  copies into `world-source.json` as the `experience` field.
- `assets/<sha256>` contains immutable runtime bytes named by their exact SHA-256
  hashes. Use [ASSET-INDEX.md](ASSET-INDEX.md) to identify their purpose,
  formats, and sizes without guessing from a hash.
- `source/caves.glb` is the cave scene input. `source/underneath-layout.json`
  defines cave authoring geometry, including the entrance, passages, landing,
  and related spatial bounds. `source/under_reef.ogg` is the ambience recording;
  `source/README-audio.md` carries its source and credit notes.
- `lod-source/cave-low.glb` is the lower-detail mesh input used to make the
  runtime LOD asset.

ElseMesh implements and validates versioned runtime behavior. Exporters,
schemas, and package tools live in the [ElseMesh engine repository](https://github.com/ElseMesh/elsemesh.github.io),
not here. Set `BURNING_HORIZONS_DIR` to this checkout when running its exporter.
The shared file definitions and review workflow are documented in [ElseMesh's
world repository layout guide](https://github.com/ElseMesh/elsemesh.github.io/blob/main/docs/world-repository-layout.md).

Regenerate the package and asset index from an ElseMesh checkout:

```sh
BURNING_HORIZONS_DIR=/path/to/burning-horizons npm run export:burning-horizons
```

Review changes to the world source and hash-named package bytes together with
their editable source changes. The asset index is generated by the exporter;
do not hand-edit it.

## Refreshing Loz source branches

The scheduled [GitHub Actions workflow](.github/workflows/mirror-loz.yml) runs
[`tools/mirror-loz.sh`](tools/mirror-loz.sh) hourly and can also be started
manually. It mirrors branches from `lozknowles/ElseMesh` and
`lozknowles/ElseMesh-preview` into this repository under `loz/` refs, preserving
replaced and deleted tips under `archive/loz-preserved/`. These are Git refs
for source tracking; they do not add upstream application files to the
Burning Horizons content package.
